# Blinkit
Summarizing the report's key data such as total ratings, sales, item weight, average ratings, and insights on sales per item and outlet, with limitations on visual extraction due to image constraints.

The dashboard contains 2 pages:
• Page 1: Executive dashboard with KPI cards and sales analysis visuals. • Page 2: Detailed outlet-level table with sales, ratings, item weight, outlet type, outlet size, location tier, and fat content.
Key KPIs shown on the dashboard:
• Total Sales: $1.20M (exactly $1,201,681.49) • Number of Items: 8,523 • Average Sales: 140.99 • Average Rating: 3.92
Main insights from the report:
• Tier 3 outlets generate the highest sales: about $472K (39.3% of total sales). Tier 2 contributes about $393K, and Tier 1 about $336K.
• High-size outlets contribute the largest share of sales (~42%), followed by Medium (~37%) and Small (~21%).
